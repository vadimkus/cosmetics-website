## 0. Проверка плана — что уточнить перед запуском

| Пункт | Проверка | Решение |
|-------|----------|---------|
| Даты из недельного плана | Даты 28 апр – 25 мая уже исторические | Использовать как последовательность: **День 1–7**, **День 8–14**, **День 15–30** |
| Статус Жанны | В диалоге не доказано, что она косметолог | Позиционировать как **лояльного клиента / рекомендателя**, не как профессионального эксперта без подтверждения |
| ROI | Нельзя считать по выручке; важна валовая прибыль | Считать по **gross profit after discount, delivery, COGS, samples** |
| Запас товара | Перед рекламой проверить stock и air freight margin | Продвигать только SKU, которых хватит минимум на 30–50 заказов |
| Professional claims | B2C аудитории нельзя продавать salon-only процедуры как домашние | Фокус только на безопасных home-care SKU и существующих протоколах |
| External площадки | The Hood by Mamahood не от Жанны, а дополнительная найденная площадка | Оставить как optional, но не считать рекомендацией Жанны |
| Платные каналы | Russian Emirates / Expat Woman могут быть дорогими | Сначала barter/community, paid — только после media kit и расчёта CAC |

**Правильный порядок:** сначала inventory + offer + tracking, потом outreach. Иначе можно получить охват, но не понять, что сработало, или продвигать SKU с плохой маржой.

## 6. ROI — простая модель (как просила Жанна)

```
Marketing ROI = (Валовая прибыль от кампании − Затраты на кампанию) / Затраты на кампанию × 100%

Валовая прибыль = выручка − скидки − COGS − delivery subsidy − payment fees − samples/barter cost
```

**Пример — Style Me (barter):**

| Статья | AED |
|--------|-----|
| Retail value набора | ~700 |
| Реальная COGS / opportunity cost | проверить по MoySklad |
| Доставка | 45 |
| Промо-скидка 10% (если 5 заказов × 700) | 350 снижения выручки |
| **Итого затратная база** | COGS + 45 + скидки |
| Нужно заказов для break-even (AOV 650–700 AED, gross margin 35–45%) | **обычно 4–6 заказов** |

**Пример — Telegram Dubai Decode (paid, допустим 3,000 AED):**

| Метрика | Цель |
|---------|------|
| Break-even при gross profit 260 AED/order | ~12 заказов |
| Охват 30K при 0.1% conversion | 30 заказов → хорошо |
| Охват 30K при 0.03% conversion | 9 заказов → ниже break-even |
| **Правило:** не платить > 2,500 AED без stats screen + beauty case study |
