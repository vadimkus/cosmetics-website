# 2026-05-01 — Real 3D Lady Hero (Hyper3D Rodin)

## What shipped

The homepage desktop hero now renders an **actual 3D head model** (PBR, rotatable, with cursor parallax), generated by Hyper3D Rodin from the photoreal reference image. Previous iteration used a flat photo + CSS molecule dots; this is a real WebGL head.

Visible at `/` on desktop (≥768 px) when WebGL is supported and reduced-motion is off. Mobile web and PWA continue to use the static photo fallback.

## Pipeline

1. Reference image: `public/images/desktop-experience/face-references/genosys-athlete-face-ref-front-down.png`.
2. Uploaded to Hyper3D Rodin (Gen-1.5) → produced a full-bust GLB with PBR textures (basecolor + normal + metallic-roughness).
3. Raw GLB: 48.7 MB, 565k vertices.
4. Optimization step (one-shot, not in a script — run manually if regenerating):
   ```
   npx gltf-transform optimize <raw.glb> public/models/desktop-experience/lady-head-real.glb \
     --compress meshopt --texture-compress webp --texture-size 1536 \
     --simplify true --simplify-ratio 0.45 --simplify-error 0.001
   ```
5. Final shipped GLB: **3.4 MB** with meshopt geometry compression and 1536 px webp PBR maps.

`@react-three/drei`'s `useGLTF` auto-wires `MeshoptDecoder` from `three/examples/jsm/libs/meshopt_decoder.module.js`, so no extra runtime config was required.

## Rendering

`components/desktop-experience/RealLadyHeroScene.tsx`:

- Studio-grade R3F scene with ACES Filmic tone mapping (exposure 0.9), `apartment` HDRI environment at 0.35 intensity, soft directional key light + warm fill + back rim, contact shadows under the bust.
- Auto-fits any GLB by computing the bounding box at runtime and centering it. Outer group carries the scale, inner group carries the offset (separate transforms — combining them on one group made the offset get scaled to nothing, which is what caused the "looking at top of head" bug mid-session).
- Subtle idle animation (tiny sin wave on Y rotation + cursor parallax). User can drag to rotate; rotation limits keep the head from showing its uncanny back.
- Skin material tuned: roughness raised to 0.65 and `envMapIntensity` lowered to 0.4 so the studio HDRI doesn't bake the face white. Hyper3D's authored Rodin shaders ship overly reflective.
- Error boundary around the model: if `lady-head-real.glb` is missing or fails to parse, the scene silently falls back to the textured-plane GLB so the hero never breaks.

`components/desktop-experience/DesktopHero3DVisual.tsx`:

- Gates on `useDesktopExperience` (≥768 px, WebGL supported, no PWA, no reduced-motion).
- When gated on: dynamic import of `RealLadyHeroScene` (`ssr: false`).
- When gated off: static `Image` of the photoreal reference (cosmetics-friendly mobile/PWA fallback).
- No more decorative CSS orbs — sparkles come from R3F now.

## Dev inspector

New route: **`/dev/3d-test`** (noindex/nofollow). Pure client component (Next 16 doesn't allow `ssr: false` from server components).

Lets you:
- Switch between any GLB in the `models/desktop-experience/` folder.
- Toggle "head" vs "fit" framing (the auto-fit math handles full-bust vs head-only models differently).
- Toggle auto-rotate.
- Toggle Three.js stats overlay (FPS, draw calls, memory).
- Drag-orbit, scroll-zoom — full inspection.

Use this whenever a new GLB lands, before swapping it into the homepage.

## Why a textured-plane fallback still exists

`genosys-athlete-face-hero-real-optimized.glb` (the previous "photo wrapped on a plane" GLB) is kept as the error-boundary fallback. It's under 1 MB, ships either way, and ensures the hero doesn't go blank if the real head GLB ever 404s. It is **not** rendered in normal operation — only on load failure.

## How to regenerate the head

If we want a different facial expression / pose / hairstyle:

1. Edit / replace the reference image in `public/images/desktop-experience/face-references/`.
2. Hyper3D Rodin → upload → "Detail" mode → GLB download.
3. Optimize with the `gltf-transform optimize` command above.
4. Save as `public/models/desktop-experience/lady-head-real.glb` (overwrite).
5. Verify on `/dev/3d-test` first.
6. Hard-reload `/` to confirm.

## Known limitations

- Hyper3D Rodin reconstructions from a single photo show seam pinching on the chest/neck region of the bust at extreme rotation angles. Fixed by clamping `OrbitControls.minAzimuthAngle` / `maxAzimuthAngle` so the user never sees the back of the model. If we ever want full 360° rotation, we need a turntable scan (Polycam / Reallusion) or an artist-authored head.
- Skin textures are albedo-only-realistic — no SSS shader. For a beauty hero this is fine; for a luxury cosmetic close-up we'd switch to `MeshPhysicalMaterial` with `transmission` / `clearcoat` and a proper subsurface profile.
