## Claim caution / traps ★ read before design

| Trap | Rule |
|---|---|
| Injectable HA / filler / “syringe volume” look | ❌ Soft **plumping / HA filling-effect** mood only |
| Invented clinical % volume / wrinkle / hydration % | ❌ Soft benefits; no fake trial numbers |
| Peptide % as “high peptide dose” | ❌ Each peptide is **0.0001%** — mention presence, not potency theater |
| Home DIY microneedling DIY hero | Soft: **professional / clinic protocol**; home only under pro guidance |
| Medical wound-healing / neocollegenesis (RU artwork tone) | Soft recovery / comfort / plump look only |
| Fragrance-free | Formula has essential oils (lavender, orange, sage…) — do **not** claim fragrance-free |
| Price on slides | Omit unless asked |
| Eyes / mucous membranes | Precaution: avoid eyes |
