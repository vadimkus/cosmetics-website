## Claim caution / traps ★ read before design

| Trap | Rule |
|---|---|
| Size 50g / 250g | ❌ This cream is **100g only** |
| Fragrance-free | ❌ Formula has Parfum / Coumarin / Linalool — Protocol_Sensitive.pdf wrongly says fragrance-free |
| Cerabarrier Biome Gel Cleanser | ❌ Different product (cleanser) — do not mix packaging or claims |
| MultiEx BSASM® Plus | Soft only — botanicals match the classic stack; do not invent clinical MultiEx % |
| “17 high-dose amino acids” | ❌ Individual amino acids are **trace** — say NMF / amino acid complex |
| Invented clinical % / 2–4 week results | Soft “restorative force” efficacy mention only if needed — **no invented %** |
| API “visible improvement within 2–4 weeks” | Avoid unless you have a verified study cite with n / dates |
| Drug / medical cure / “heals eczema” | Cosmetic soothing · hydrating · barrier protect only |
| Macadamia / Meadowfoam as hero % | Tiny in Formula_up — keep as soft nourishing oils, not dose heroes |
