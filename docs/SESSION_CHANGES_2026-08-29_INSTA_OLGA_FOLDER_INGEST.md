## Master Production System 4.0 (read in full)

**Contract:** do not improvise, approximate, or “improve.” Locked value = exact reproduction. If exact is impossible, stop and change method. One final per request. Beauty does not override accuracy.

**Source priority when they conflict** (AI does not choose):

1. Client-confirmed written lock  
2. Original real packshot / packaging (geometry, printed artwork, physical colour)  
3. Current official product page  
4. Official technical / clinical file  
5. Official catalogue / manual  
6. AI memory — never a factual source  

**Hard locks that matter for the work we already did on Hydro Cool:**

- Never rebuild visible packaging from scratch when an original packshot exists.
- Never redraw or retype packaging logos, label microtext, pictograms.
- Never change pack geometry. Overlay silhouette test at same height = fail if it diverges.
- Protected assets: COPY / PLACE only. No regenerate, restyle, recolour, “clean up.”
- Campaign type is **Helvetica Neue** (UltraLight 100 display, Light 300 support). Packaging text stays original artwork. If the generator cannot guarantee the font, it must not render final campaign text.
- Black `#000000` / supporting `#161616` / background `#FFFFFF`. Accent sampled from that product’s pack.
- Hero A = 1:1 product only, no headline. Hero B = independent 4:5, do not crop Hero A.
- Content carousel 5–7 as a working range, not a quota. Max two face slides, never consecutive.
- **Final slide:** exact real product + verified credentials only + two locked purchase routes: **SHOP GENOSYS.AE** + **GENOSYS UAE APP**. Locked outline icons (open bag + outlined phone). No cart, QR, stars, price stickers.
- Story 1080×1920. Critical zone x 90–990, y 250–1600. Bottom is not design space. Pain first, product second.
- “Dermatologically Tested” / “Made in Korea” only when verified for that SKU.

This is the document that should govern Olga carousels going forward. The Hydro Cool Closing slide already matches the final-slide system (1 KG, derm-tested, Made in Korea, two CTAs).
